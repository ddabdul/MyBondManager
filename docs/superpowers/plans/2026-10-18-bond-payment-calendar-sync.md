# Automatic bond payment calendar sync

Approved intent: send iPhone payment-day reminders via a dedicated iCloud Calendar. Additions, approved edits, imports, deletions and refreshed projections automatically reconcile future events while MyBondManager runs. Already-synced reminders work with the Mac off. These are expected-payment reminders, never bank receipt confirmation.

Implementation uses native EventKit, full Calendar permission on explicit enable, and a user-selected CalDAV/iCloud account. Never silently use a local or other account. Only app-marked events in the persisted dedicated calendar are changed. Group approved canonical receipts by normalized ISIN plus adjusted payment day; sum coupon and full redemption separately. Preserve past events and unrelated user events. Excluded schedules are visible; unexpected projection/fetch errors abort before calendar mutation. Persist enabled/account/calendar/options and expose last sync and errors. Default alarm: 09:00 in the Mac time zone when synced; optional day-before alert and amount-free titles. Disabling stops updates and explicitly leaves existing events/alerts intact.

1. Tests and immutable projection/reconciliation: canonical amounts, grouping, adjusted dates, exclusions, projected warnings, alert dates/DST, stable event identity, duplicate removal, stale future removal and past retention.
2. Native EventKit store and observable coordinator: serialized off-main EventKit access; bounded date queries; staged commit/reset on failure; source selection, permission denial, calendar persistence, save/launch/foreground/day-change triggers with coalescing. No credentials, hosted service or portfolio schema migration.
3. Calendar settings sheet and Cash Flows toolbar access; entitlement and privacy text. Integration tests against an isolated portfolio and recording calendar store; no tests access live calendars or send messages. Full tests, independent review, universal build and package verification. User performs the actual Calendar permission and iPhone delivery check.
